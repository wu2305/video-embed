# Colour

Two themes from one set of tokens. Each colour in `src/styles.css` is `light-dark(<light>, <dark>)`:
a page follows the OS setting, and `data-theme="light"` or `"dark"` on any element pins that subtree,
so both themes can render on one page. Dark is the console's own palette and the default here.

Use the **Theme** toolbar to switch any story, or pick **Side by side** to see both at once.

Face boxes, rank and score chips and the note over the frame sit on a photo, not on a theme surface,
so they keep these values in both themes. A face box is never one colour on the photo: a white ring
between two dark halos always has one edge that clears 3:1, whatever the frame. Its state (named, untagged,
selected) is the fill of its label chip, plus a dashed ring for untagged and a thicker ring for selected.

## Rules

- `text` on `bg`, `panel` and `field`. `muted` for labels, metadata and ghost buttons. Every text colour
  is at least 4.5:1 on all three surfaces in both themes; `npm test` checks every story in each.
- `accent` is the single interactive colour, and each role has its own treatment so they never look alike:
  an action is filled accent (the primary button); focus is a 2px accent outline set 2px off the control;
  selection is a 2px accent border plus `accent-wash` (a selected card, chip or note); a link is accent text,
  underlined on hover. The brand mark is accent too. `accent-strong` is the primary button under hover and press.
- A disabled or `aria-disabled` button is `muted` on `field` with a `line-strong` border, never faded with
  opacity: an `aria-disabled` button stays focusable to explain why, so its label must stay readable.
- `good` means *matched* (scene range, score, saved). `warn` means *look twice* (copy, merge, unnamed).
  `bad` means *blocked* (error, no such person), and outlines a `danger` button such as *Merge into Ana Ruiz*.
- Every signal colour sits next to a word or number. Green and red are close in lightness in both themes,
  so hue alone never carries meaning.
- `line` is a separator (about 1.3:1). `line-strong` (at least 3:1 on every surface) bounds anything you act on
  or read as a unit: inputs, buttons, panels, cards, notes and the timeline track.
- The timeline's matched range is a green wash with a `good` edge, and the key under the track names it.
- In dark, `muted` is bright enough for 12px text, so the gap to `text` is small: hierarchy comes from size
  and weight, not lightness alone.
- Never write a hex value in a component. If a colour is missing, add a token with both theme values.
